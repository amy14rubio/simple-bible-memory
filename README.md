# Simple Bible Memory

A free app for memorizing Bible verses with spaced repetition. You rate how well you remembered a verse, and the app decides when to show it again. Works offline, no account needed, in English and Spanish.

[Website](https://simple-bible-memory.web.app) · [Google Play](https://play.google.com/store/apps/details?id=app.simplebiblememory) · [App Store](https://apps.apple.com/us/app/simple-bible-memory/id6827304569)

It is a React + TypeScript web app, also published for Android and iPhone/iPad with [Capacitor](https://capacitorjs.com).

## Run it

```bash
git clone https://github.com/amy14rubio/simple-bible-memory.git
cd simple-bible-memory
npm install
npm run dev
```

No keys needed. More in [docs/development.md](docs/development.md); how the code is organized is in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
